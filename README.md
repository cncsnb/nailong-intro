# 奶龙国际大学视频开场页

打开页面先显示 10 秒的奶龙新生护送动画。可以点击“立即前往”提前进入，按住“按住不走”暂停倒计时，松手后继续。动画完成后进入视频开场页。

静态网站：15 秒视频优先尝试有声自动播放；若浏览器限制有声自动播放，自动切换为静音播放，可点击“开启声音”恢复声音。进入视频开场页 8 秒后可点击跳过，前往 https://www.bnbu.edu.cn/。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，发布 main 分支的根目录 / (root)。

仓库根目录包含 index.html、nailong-mascot.png、video.mp4 和 .nojekyll，不需要安装依赖或构建。

先使用 GitHub Pages 返回的网址测试页面与视频。确认目标网络能够访问后，再绑定自定义域名。
