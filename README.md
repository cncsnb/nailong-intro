# 奶龙国际大学视频开场页

静态网站：15 秒视频默认开启声音，尝试有声自动播放；如果浏览器限制自动播放，可点击播放按钮。打开页面 5 秒后可点击跳过，前往 https://www.bnbu.edu.cn/。点击“关闭声音”可静音。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，发布 main 分支的根目录 / (root)。

仓库根目录包含 index.html、video.mp4 和 .nojekyll，不需要安装依赖或构建。

先使用 GitHub Pages 返回的网址测试页面与视频。确认目标网络能够访问后，再绑定自定义域名。
